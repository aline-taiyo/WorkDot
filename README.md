# WorkDot

다우오피스(DaouOffice) 근태 현황을 실시간으로 동기화하고 화면 경계에 깔끔하게 고정해 사용하는 Windows 미니 오버레이 위젯입니다.

- **최신 버전**: `v1.5.4`
- **저장소**: https://github.com/aline-taiyo/WorkDot
- **최신 릴리즈 다운로드**: https://github.com/aline-taiyo/WorkDot/releases/latest

---

## 1. 시작 및 다우오피스 연동

1. `WorkDot.exe`를 실행하면 화면 우측 하단(작업 표시줄 위 경계)에 미니 위젯이 표시됩니다.
   - 작업 표시줄에는 아이콘이 노출되지 않으며, **시스템 트레이(트레이 아이콘)** 및 오버레이 위젯으로만 동작합니다.
2. 최초 실행 시(또는 로그인이 필요한 경우):
   - 위젯에 마우스를 올려 확장된 아이콘 바에서 **홈(브라우저 열기)** 버튼을 클릭하거나, 위젯 우클릭 메뉴에서 **`브라우저 열기`**를 선택합니다.
   - 내장된 다우오피스 창에서 **1회 로그인**하면 세션 쿠키와 계정 정보가 Windows DPAPI로 안전하게 암호화 저장되어 이후 재실행 시에도 자동으로 로그인·동기화됩니다.

## 2. 위젯 화면 구성 및 표시 방식

| 상태 / 모드 | 동작 설명 |
| --- | --- |
| **기본 미니 모드** | 평소에는 **근무중(해 아이콘, 초록)** 또는 **퇴근(달 아이콘, 빨강)** 배지만 미니멀하게 표시됩니다. |
| **마우스 호버 확장 모드** | 위젯 위에 마우스 커서를 올리면 우측에 **홈(브라우저 열기) · 새로고침 · 환경설정** 아이콘 바가 펼쳐집니다. |
| **실근무 경과 시간 표시** | 근무중 상태에서 위젯을 **10초 이상 건드리지 않으면**, 다우오피스 출근 시각 및 휴게시간(점심시간 등)을 제외한 **실근무 경과 시간(`HH:mm`)**이 자동으로 함께 표시됩니다. |
| **화면 경계 자석 스냅** | 위젯을 드래그하면 자동으로 미니 모드로 전환되며, 모니터 및 작업 표시줄 경계에 빈틈없이 자석 스냅됩니다 (히스테리시스 버퍼 적용으로 경계 이동 시 떨림 방지). |

## 3. 출근 / 퇴근 전환 방법 (롱프레스 + Press Up)

실수로 클릭하여 출퇴근이 변경되는 것을 방지하기 위해 **상태 아이콘을 꾹 누른 뒤(약 0.45초) 위젯 안에서 마우스를 떼는(Press Up)** 방식으로 동작합니다.

### 퇴근하기 (근무중 → 퇴근)
1. **근무중(해 아이콘)** 상태에서 아이콘을 **꾹 누르고 있으면** 배지 색상이 빨간색으로 강조됩니다.
2. 위젯 영역 안에서 **마우스 버튼을 떼면(Press Up)** 위젯 근처에 **`"퇴근 할래요?"`** 팝업이 열립니다.
3. **`Y`** 버튼 클릭(또는 키보드 `Y` / `Enter`) 시 즉시 **퇴근** 상태로 전환되며 다우오피스 퇴근 처리를 수행합니다 (`N` 또는 `Esc` 선택 시 취소).

### 출근하기 (퇴근 → 출근)
1. **퇴근(달 아이콘)** 상태에서 아이콘을 **꾹 누르고 있으면** 배지 색상이 초록색으로 강조됩니다.
2. 위젯 영역 안에서 **마우스 버튼을 떼면(Press Up)** 별도 확인 팝업 없이 **즉시 출근(근무중)** 상태로 전환됩니다.

### 취소하기 (위젯 바깥에서 마우스 떼기)
- 아이콘을 꾹 누른 상태에서 **마우스 커서를 위젯 바깥으로 이동한 뒤 마우스 버튼을 떼면(Press Up)** 강조 표시가 해제되며 **아무 동작도 하지 않고 무시**됩니다.
- 아이콘을 길게 누르기 전에 마우스를 바로 이동하면 위젯 위치 **드래그 이동**으로 동작합니다.

## 4. 마우스 조작 및 단축 메뉴

- **드래그 이동**: 위젯을 마우스로 잡고 이동하면 화면 상·하·좌·우 및 작업 표시줄 경계에 스냅됩니다.
- **크기 빠른 조절**: 위젯 위에서 `Ctrl + 마우스 휠`로 위젯 배율(`70% ~ 160%`)을 즉시 조절할 수 있습니다.
- **우클릭 컨텍스트 메뉴**:
  - `퇴근하기 / 출근하기`
  - `환경설정`, `브라우저 열기`, `새로고침`
  - `항상 위에 표시`, `Windows 시작 시 자동 실행`, `위젯 크기 (80% ~ 140%)`
  - `상태 전환 (근무 / 퇴근 수동 전환)`, `윈도우 경계 정렬`, `숨기기`, `종료`
- **시스템 트레이 아이콘**:
  - **좌클릭**: 위젯 보이기 / 숨기기 토글
  - **더블클릭**: 다우오피스 브라우저 창 열기
  - **우클릭**: 컨텍스트 메뉴 열기

## 5. 환경설정 및 자동 업데이트

위젯의 **톱니바퀴(환경설정)** 아이콘을 클릭하여 다음 항목을 설정할 수 있습니다 (`%LOCALAPPDATA%\WorkDot\settings.json`에 자동 저장).

- **테마 모드**: `Windows 시스템 설정 따름` / `다크 모드` / `라이트 모드`
- **상태 색상 커스터마이징**: 근무중(출근) 및 퇴근 색상을 프리셋 스와치 또는 HEX 코드(`#10B981`, `#EF4444` 등)로 변경
- **위젯 외관**: 투명도(`25% ~ 100%`) 및 크기 배율(`70% ~ 160%`) 슬라이더 조절
- **실행 및 업데이트**:
  - `항상 위에 표시 (Topmost)`
  - `Windows 시작 시 자동 실행`
  - **`최신 릴리즈 자동 업데이트`**: 활성화 시 앱 시작 및 주기적으로 GitHub 최신 Release를 확인하여 새 버전이 있으면 자동 설치 후 재시작
  - **`업데이트 확인` / `저장소 열기`**: 수동으로 최신 릴리즈를 즉시 확인하거나 GitHub 저장소를 브라우저에서 열기

## 6. 빌드 및 릴리즈 배포

### 로컬 빌드 및 실행
```powershell
dotnet build WorkDot.slnx -c Release
.\run.bat
```

### 새 버전 GitHub Release 배포
1. `src/WorkDot/WorkDot.csproj`의 `<Version>`을 올리고 커밋합니다.
2. 태그를 생성하여 GitHub에 푸시하면 GitHub Actions(`.github/workflows/release.yml`)가 자동으로 `WorkDot-win-x64.zip`을 빌드해 **GitHub Releases**에 게시합니다:
   ```powershell
   git tag v1.5.4
   git push origin main --tags
   ```
3. 로컬에서 배포용 ZIP 파일(`dist\WorkDot-win-x64.zip`)을 직접 생성하려면 `.\publish-release.bat`를 실행합니다.
