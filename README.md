# WorkDot

다우오피스(DaouOffice) 근태 현황을 실시간으로 확인하고 원클릭으로 출근/퇴근을 처리할 수 있는 Windows 데스크톱 오버레이 위젯입니다.

## 주요 기능

- **직관적인 상태 가시성**: 근무중(초록 발광 펄스) / 퇴근·미출근(빨강 발광 펄스) 상태를 캡슐형(Pill) 또는 미니 점(Dot) 위젯으로 표시
- **창 경계 자석 스냅 & 동반 이동**: 작업 표시줄이나 다른 실행 중인 앱 창의 테두리에 자석처럼 스냅되며, 스냅된 앱 창이 이동·크기 변경될 때 함께 이동 (`DwmGetWindowAttribute` + `SetWinEventHook`)
- **다우오피스 그룹웨어 연동**: 내장 `WebView2` 세션 공유를 통해 `my-attendance-status` 페이지와 자동 동기화 및 원클릭 출근/퇴근 처리
- **다양한 환경설정 지원**:
  - Windows 시스템 테마(라이트/다크) 자동 연동 및 수동 테마 지정
  - 출근(근무중) / 퇴근 표시 색상 커스터마이징 (프리셋 팔레트 및 HEX 코드)
  - 위젯 투명도(`25% ~ 100%`) 및 크기 배율(`70% ~ 160%`, `Ctrl + 마우스 휠`) 실시간 조절
  - 항상 위에 표시(`Topmost`) 및 Windows 시작 시 자동 실행 등록

## 빌드 및 실행

```powershell
dotnet build -c Release
.\run.bat
```
